VOICE HDK - FIXED PACKAGE

1. Upload toàn bộ thư mục/repository lên Render.
2. Build Command: npm install
3. Start Command: npm start
4. Environment Variables bắt buộc:
   DISCORD_TOKEN
   DATABASE_URL
5. PORT do Render cấp tự động; file vẫn có fallback 10000.
6. Chạy npm run check để kiểm tra cú pháp nếu cần.

Lưu ý: Không đưa file .env chứa token thật lên GitHub.
